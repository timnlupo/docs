## Welcome

The Deeptune API provides endpoints for managing test environments and grading agent tasks. The API allows you to reset test environments, run tests, and grade results.

## Authentication

All API endpoints require authentication using an API key. Include your API key in the `X-API-Key` header with all requests:

```json
{
  "X-API-Key": <YOUR_API_KEY>
}
```
