## How it works

Deeptune provides batteries included apps to train computer use agents. Each app comes with the infrastructure to easily test, reset, and grade for 1000s of parallel agents.

Apps come preloaded with workspace/user data to simulate a real, "lived in" app. It also comes prebuilt with tests and grading -- each test has a bespoke set of criterion we check for in the database to ensure the action was successful.

### Using the Platform

The flow works as follows:

1. Login with provided credentials to each app.
2. Reset the environment for this account. This will reset it to the original "preloaded" state.
3. Run your test.
4. When the test is finished, grade the result.
