## Overview

[Huly](https://huly.io) is an open-source platform that serves as a replacement for tools like Linear, Jira, Slack, and Notion. It provides teams with a unified workspace for project management, communication, and documentation.

## Accessing Huly

Contact support for your login credentials.

Each user is distinct and in identical, parallel environments. This means any change in one user will not impact the environments of the other uses.

## Resetting Huly

Each account can be reset to the original state at any time. See the [reset API reference](/api-reference/accounts) for more information.

## Huly Test Suite

Deeptune comes with tests and grading specific to Huly. All tests assume the account is in the original workspace state, so be sure to reset before running any tests.

Tests can be fetched [via the tests API](/api-reference/tests-&-grading/get-tests) and graded via the [grading API](/api-reference/tests-&-grading/grade-test) for more information.
